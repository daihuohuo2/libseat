# 座位助手 · Android 0.3.0

手机独立运行，无需电脑开机。最低 Android 8.0，建议更新 Android System WebView。

从 [GitHub Releases](https://github.com/daihuohuo2/libseat/releases) 下载 `seat-assistant-0.3.0.apk`，传到手机安装。保留旧版应用直接覆盖安装，可保留手机里的登录状态、偏好与记录。此包使用项目本地体验版密钥签名，未发布应用商店。

0.3.0 新增“盯指定座位”：目标空闲后自动预约；已有预约则取消后换座，已签到或临时签离则完全签离后换座。仅预约指定座位。保留 0.2.1 的隔天预约清理、重新登录和手动刷新修复。

## 使用

1. 打开“登录 → 登录学校账号”，在学校页面完成认证。
2. 选择区域，加入抢选名单。可在“座位偏好”逐个选择、输入范围或不限座位。
3. 需要实际预约时关闭“仅观察空位”，点击“开始抢座”。红色显示自己的有效预约。
4. 在地图上方开启定时重约：选择当前或下次预约、到馆时间，用滑块选择 30～59 分钟，默认 50 分钟。
5. 未签到时可取消预约；签到后“查看位置信息”中可临时签离或完全签离。学校要求定位时，请允许定位权限。
6. 只想等一个座位时，在地图选择区域，点击“盯指定座位 → 选择座位”，输入一个编号，关闭观察模式并“开始盯座”。目标被占用时保留原座位，空闲后按官网状态取消或完全签离，再预约目标；成功后按学校要求重新签到。
7. 通知栏可停止抢座、重约与盯座。帮助说明集中在右上角“使用帮助”。

“体验演示”使用独立的模拟记录，不向学校发请求，支持地图、预约、重约、取消和签离。完成演示预约后可点击“模拟到馆签到”，体验临时和完全签离。模拟签到仅存在于演示模式。

## 后台与限制

- 抢座、定时重约和盯座使用 dataSync 前台服务、常驻通知及唤醒锁。请允许通知、后台运行，并保持网络连接。
- 省电策略、系统回收、强制停止及 Android 前台服务时限可能中断任务。到馆、检测到签到、手动停止或操作结果不明时停止重约。
- 正常等待阶段重启会恢复已保存的重约计划，并在执行前核实官网状态；普通抢座不会自动恢复。取消或预约过程中被终止，只核实结果，不重复提交。
- 盯座只支持当天、单个目标，与普通抢座和重约互斥。跨日、登录变化、修改时段或重启后暂停，需重新开启；结果不明时先核实。原座位释放后目标仍可能被抢走，无法保证找回原座位。
- 学校要求定位时需允许定位，并保持应用前台以更新当前位置；定位或官网校验失败时暂停并显示原因。
- 30～59 分钟是执行间隔，不是学校授予的签到期限。58、59 分钟可能赶不上官网期限，实际操作仍以官网允许的状态为准。
- 已进行模拟接口回归和 Android WebView 原生桥接流程验证。未替用户取消真实预约或执行真实签离；学校账号、定位规则与网络仍须在本人手机上验证。

## 构建与测试

需要 JDK 21、Node.js、Android SDK（API 36 或以上平台及 build-tools）。不依赖 Gradle。

```powershell
# 在仓库根目录执行
./android/build.ps1 -Sdk D:/Android/Sdk -Java D:/Java
node --test tests/*.test.js
```

输出为 `android/output/seat-assistant-0.3.0.apk`，使用本地 `android/local-debug.keystore` 签名。保留该密钥以便覆盖安装；源码和发布包不包含密钥、账号或历史数据。

对专用 Android 模拟器运行原生流程测试（只重置模拟器应用的演示数据）：

```powershell
./android/test.ps1 -Sdk D:/Android/Sdk -Java D:/Java -Serial emulator-5554
```

测试 APK 与正式包分开构建。测试通过真实 WebView、原生桥接和文件存储检查：地图、抢座、滑块间隔、到时同座重约、后台服务、取消停止重约、到馆状态、临时签离、完全签离、重新登录刷新、手动刷新、隔天返回时清除旧标记和再次预约，以及指定座位占用时保留原座位、前台服务持续运行、目标空闲后完全签离并预约目标。测试时钟和自动确认不会打进发布 APK。

## 架构

- `EngineService` 在独立 WebView 中运行共享预约引擎；不开放本地 TCP 端口。
- `MainActivity` 提供应用页面、学校登录页、文件导入导出和定位授权。
- `web/engine-runtime.js` 适配 HTTP、AES、文件、定时器和原生通知。
- `prepare-assets.js` 按白名单打包资源，真实和演示数据位于不同私有目录，关闭系统备份。
- 学校页面没有原生 JavaScript 桥；特权页面只加载本地资源，网络只允许学校 HTTPS 主机，证书异常不会被忽略。
