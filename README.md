# LibSeat · 中南大学图书馆座位助手

本地运行的座位查询和预约工具。登录学校预约系统后，按选定区域持续查询空位，预约成功后停止。

支持浏览器界面、Windows 轻量窗口、Electron 桌面版和 Android 体验版。项目为个人开发的辅助工具，与学校及预约系统运营方无隶属关系；使用时请遵守图书馆预约规则。

## 功能

- 校区、楼层、区域与座位状态查询。
- 心仪座位优先级、区域偏好与方案保存、导入和导出。
- 仅观察空位或按所选日期、时段尝试预约。
- 预约成功弹窗、系统通知与最近预约记录。
- 请求结果不确定时暂停提交，核实后再继续，避免重复预约。
- 桌面托盘控制，以及无需账号的模拟界面预览。

## 环境要求

- Node.js 22.12 或以上，需支持内置 `fetch` 和 `WebSocket`，并满足桌面端依赖要求；本次验证使用 Node.js 24。
- Windows 上的自动登录与轻量窗口需要安装在常见默认路径的 Microsoft Edge 或 Google Chrome。
- 实际预约需要本人有效的学校账号，以及能够访问学校座位系统的网络。
- 网页后端只使用 Node.js 内置模块；Electron 桌面版需要单独安装依赖。

## 获取与启动

```powershell
git clone https://github.com/daihuohuo2/libseat.git
cd libseat
node server.js
```

浏览器访问 **http://127.0.0.1:8848**。首次使用无需复制配置文件；登录或保存设置后，会在本地生成 `config.json`。

### Windows 启动方式

- 网页版：双击 `start.bat`，访问 `http://127.0.0.1:8848`。
- 轻量窗口：双击 `座位助手.vbs`，需要 Node.js 和 Edge / Chrome。
- Electron 桌面版：在项目目录执行以下命令。

```powershell
cd desktop
npm ci
npm start
```

### 首次使用

1. 在“登录管理”中打开学校登录页，并在官网完成认证。
2. 选择校区、楼层和区域，配置心仪座位或方案。
3. 检查日期、时间段和查询间隔。默认开启“仅观察空位，不提交预约”。
4. 确认需要预约时关闭观察模式，再启动任务；可随时手动停止。

### 无账号预览

```powershell
node tools/ui-preview.js
```

访问 **http://127.0.0.1:8850**。预览使用内存中的模拟数据，不读写正式登录配置，不向学校提交预约，重启后会清空预览方案。

### Android 体验版

Android 版在手机上独立运行，无需电脑保持开机，最低支持 Android 8.0。源码、构建步骤和模拟器测试说明见 [Android README](android/README.md)。仓库不包含预编译 APK 或本地签名密钥，请按说明构建。

## 成功提醒

预约接口确认成功后，页面会弹出结果，显示座位号、区域、日期和实际提交的预约时段。关闭弹窗后，页面顶部保留结果，可点击“查看预约结果”重新打开。

- 网页版和轻量窗口：点击“开启桌面通知”，允许浏览器发送通知。未允许通知时仍有页面弹窗。
- Electron 桌面版：自动发送系统通知，最小化时继续检查结果，点击通知可恢复窗口。系统的通知设置和免打扰模式可能影响横幅显示。
- 同一次预约的通知状态保存在本地，连续轮询、刷新页面和重启后不会重复弹出。新一次成功预约会重新提醒。
- “安全模式”只查询空位，不提交预约，也不会显示成功通知。

开始任务时会保存页面上的最新日期、时段、轮询间隔和观察模式设置。点击停止后，尚未发出的预约不再提交；已经发出的请求仍需等待学校接口返回结果。

## 超时核实与预约记录

提交预约只发送一次。请求超时、断网或响应无法解析时，程序暂停抢座并查询已有预约；只有有效状态、座位、日期和起止时段都匹配，才确认成功。暂未查到记录不能证明预约失败，因此不会直接重试或换座。

如果自动核实无法完成，页面提供“重新核实”和官网入口。请到官网核实对应座位和时段，再选择“官网已确认成功”或“官网已确认未成功”。确认未成功后，需要手动开始下一次任务。

待确认请求、最近 50 条已确认结果和通知状态保存在配置文件旁的 `bookings.json`，不包含登录令牌。请求发出前先保存待确认记录，重启后会恢复并尝试核实；页面“最近预约记录”可查看历史结果。文件损坏或无法写入时会显示错误并阻止新的预约提交。

自动核实根据本项目归档的官网页面解析预约记录接口，仅提取接口路径，不执行下载的脚本。当前依赖官网 `sear-record.1787201907183.js` 的接口声明和记录字段；官网升级或连接不可用时会保留待确认状态。本次验证使用模拟接口，实际官网连接因 TLS 握手失败，尚未完成在线核实测试。

## 托盘与时间检查

- Electron 桌面版关闭窗口后缩到托盘，继续运行。托盘显示正在抢座、已成功、已停止或结果待确认；双击恢复窗口，也可右键停止任务或退出。
- 网页版和轻量窗口保留原有退出方式。浏览器标签页关闭后，页面通知不可用。
- 实际预约在启动、每轮查询及最终提交前检查日期、开放时间、最长时长和时间粒度。查询期间更改区域或时段，会重新查询，避免使用旧配置提交。

## 验证

如果校区、楼层或地图加载失败，页面会显示原因，并提供“重新登录”“重新加载”和官网入口。登录过期时先重新登录，完成后自动加载地图；若提示无法连接学校，请先确认官网在当前网络下能够打开。失败后自动刷新会暂缓，避免重复请求排队。

在本目录运行：

```powershell
node --test test-notifications.js test-recovery.js
node test-prefs.js
```

通知回归测试使用独立临时配置和模拟接口，不读取或覆盖现有登录配置，不提交真实预约。安装了 Electron 时，还会检查实际渲染页面的成功弹窗、通知去重和未允许系统通知时的页面提醒。

主要文件：`server.js` 为后端和预约引擎，`booking-store.js` 保存预约状态，`booking-window.js` 校验时段，`reservation-records.js` 解析官网记录接口并匹配预约，`public/index.html` 为界面，`public/booking-notifications.js` 负责成功结果格式和通知去重，`browser-login.js` 负责获取登录态，`desktop/main.js` 为桌面入口。

## 项目结构

```text
libseat/
├── server.js                 # 本地服务与预约引擎
├── browser-login.js          # 学校登录状态获取
├── booking-store.js          # 预约状态与历史记录
├── booking-window.js         # 预约时段校验
├── reservation-records.js    # 结果核实与记录匹配
├── seat-prefs.js             # 座位偏好与候选排序
├── public/                   # 网页、样式、图标和字体
├── desktop/                  # Electron 桌面入口
├── android/                  # Android 源码与构建脚本
├── tools/                    # 模拟预览与图标工具
├── mock-api.js               # 测试用模拟接口
└── test-*.js                 # 回归测试与开发检查
```

## 本地数据与配置

`config.json` 保存登录令牌和偏好；`bookings.json` 保存待核实请求、预约历史和通知状态；`browser-data/` 和 `.app-profile/` 保存浏览器会话。它们以及日志、签名密钥和构建产物均已加入 `.gitignore`，不会随源码上传。不要手动分享这些文件。

服务默认只监听本机回环地址。需要隔离测试数据时，可以设置以下环境变量：

| 变量 | 用途 |
| --- | --- |
| `PORT` | 后端监听端口，默认 `8848` |
| `LIBSEAT_CONFIG_FILE` | 配置文件路径 |
| `LIBSEAT_BOOKINGS_FILE` | 预约记录文件路径 |
| `LIBSEAT_LOG_FILE` | 日志文件路径 |

## 已知限制

- 目前适配中南大学图书馆座位系统，不保证其他学校可直接使用。
- 学校接口、认证方式或静态资源版本变化可能导致功能失效。
- 自动登录依赖本机浏览器和有效学校会话，失效时需要重新登录。
- 模拟测试不等于真实预约验证；本仓库不保证预约成功或后台长期持续运行。移动端测试范围见 Android README。
- `probe*.js`、`shot-refresh.js`、`verify-ui.js` 等是开发诊断脚本，部分会连接学校系统或现有浏览器，不属于上面列出的隔离回归测试。
