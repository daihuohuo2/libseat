# LibSeat · 中南大学图书馆座位助手

本地运行的座位查询和预约工具。登录学校预约系统后，按选定区域持续查询空位，预约成功后停止。

支持浏览器界面、Windows 轻量窗口、Electron 桌面版和 Android 体验版。项目为个人开发的辅助工具，与学校及预约系统运营方无隶属关系；使用时请遵守图书馆预约规则。

## 功能

- 校区、楼层、区域与座位状态查询。
- 抢选名单内区域无优先级，有空位即尝试；支持跨楼层、跨馆及方案保存、导入和导出。
- 仅观察空位或按所选日期、时段尝试预约。
- 预约成功弹窗、系统通知与最近预约记录。
- 请求结果不确定时暂停提交，核实后再继续，避免重复预约。
- 主动开启的定时取消并重约：滑动选择 30～59 分钟间隔（默认 50），管理同一座位，到预计到馆时间或签到后停止。
- 桌面托盘控制，以及 Android 内置体验演示。

## 环境要求

- Node.js 22.12 或以上，需支持内置 `fetch` 和 `WebSocket`，并满足桌面端依赖要求；本次验证使用 Node.js 24。
- Windows 上的自动登录与轻量窗口需要安装在常见默认路径的 Microsoft Edge 或 Google Chrome。
- 实际预约需要本人有效的学校账号，以及能够访问学校座位系统的网络。
- 网页后端只使用 Node.js 内置模块；Electron 桌面版需要单独安装依赖。

## 获取与启动

```powershell
git clone https://github.com/daihuohuo2/libseat.git
cd libseat
node server.js
```

浏览器访问 **http://127.0.0.1:8848**。首次使用无需复制配置文件；登录或保存设置后，会在本地生成 `config.json`。

### Windows 启动方式

- 网页版：双击 `start.bat`，访问 `http://127.0.0.1:8848`。
- 轻量窗口：双击 `座位助手.vbs`，需要 Node.js 和 Edge / Chrome。
- Electron 桌面版：在项目目录执行以下命令。

```powershell
cd desktop
npm ci
npm start
```

### 首次使用

1. 在“登录管理”中打开学校登录页，并在官网完成认证。
2. 选择校区、楼层和区域，配置心仪座位或方案。
3. 检查日期、时间段和查询间隔。默认开启“仅观察空位，不提交预约”。
4. 确认需要预约时关闭观察模式，再启动任务；可随时手动停止。

### Android 体验版

Android 版在手机上独立运行，无需电脑保持开机，最低支持 Android 8.0。源码、构建步骤和使用说明见 [Android README](android/README.md)。可从 [GitHub Releases](https://github.com/daihuohuo2/libseat/releases) 下载 APK，或按说明构建；Git 历史不包含安装包和签名密钥。

## 成功提醒

预约接口确认成功后，页面会弹出结果，显示座位号、区域、日期和实际提交的预约时段。关闭弹窗后，页面顶部保留结果，可点击“查看预约结果”重新打开。

- 网页版和轻量窗口：点击“开启桌面通知”，允许浏览器发送通知。未允许通知时仍有页面弹窗。
- Electron 桌面版：自动发送系统通知，最小化时继续检查结果，点击通知可恢复窗口。系统的通知设置和免打扰模式可能影响横幅显示。
- 同一次预约的通知状态保存在本地，连续轮询、刷新页面和重启后不会重复弹出。新一次成功预约会重新提醒。
- “安全模式”只查询空位，不提交预约，也不会显示成功通知。

开始任务时会保存页面上的最新日期、时段、轮询间隔和观察模式设置。点击停止后，尚未发出的预约不再提交；已经发出的请求仍需等待学校接口返回结果。

抢选名单是区域集合，添加顺序不代表优先级，也不受地图当前校区、楼层或旧版全局心仪座位设置限制。实际提交前读取该区域官网规则，并按实际预约时段查询座位：整段预约提交官网时段编号，自选时段提交按官网规则校验的起止时间。地图上的当前空闲数不保证整个预约时段都可用。实时模式使用官网整段时段时，结束时间可能与旧版默认四小时窗口不同，成功提醒以实际时段为准。

在区域下拉框旁点击“设置本区域座位偏好”，或点击抢选名单中该区域的“设置”：

- **不限座位**：本区域任何可约空位都可以。
- **优先选定座位**：可逐个点击编号，也可输入 `149, 150, 160-170`，范围包含首尾；支持完整座位号，并只接受当前区域实际存在的编号。当前被占用的座位也可以加入偏好。
- 先尝试该区域当前可约的优先座位；优先座位没有空位或明确被别人抢走时，继续尝试同一区域的其他空位。区域之间仍无优先级。请求结果不明时仍会暂停核实。
- 偏好按区域分别保存，保存、导出、导入和套用方案时一起带上；旧方案没有座位偏好时默认不限。选择“不限座位”会清除该区域的优先列表。

更新后需要退出并重启后台。若只刷新网页，偏好面板会提示重启旧后台，避免显示保存成功但实际未生效。

若官网返回“未选择或申请时间错误”，任务停止并直接显示原因，避免反复发送无效请求。普通座位已被抢占时继续尝试其他候选；单个区域查询失败也会继续检查其他已选区域。

## 定时取消并重约

更新代码后需**退出并重新启动后台**，刷新页面。地图上方显示“定时重约”，详细用法收在右上角“使用帮助”。仅更新网页而未重启旧后台时，面板会明确提示重启。

1. 已通过本工具预约成功：选择“当前预约”；尚未预约：先关闭“仅观察空位”，选择“下次预约”。当前预约必须是今天的本地成功记录，并能在官网核实为未签到、允许取消的同一笔预约。
2. 填写今天预计到馆时间，例如 `14:00`，滑动选择 30～59 分钟间隔（每格 1 分钟，默认 50），点击“开启定时重约”。修改间隔需先停止再开启，已开启的间隔随计划保存并在重启后恢复。选择下一次预约时，再点击“开始抢座”。开启计划不会自动发起首次抢座。
3. 每次按实际预约时间和所选间隔计时，先查询本人官网记录及最新预约规则，再发送一次取消请求。官网确认取消成功后，只尝试一次原座位重约。整段预约使用官网时段编号，按当前时间开始、在原时段结束；自选时段按官网时间粒度顺延并保留原时长，不超过闭馆时间。
4. 到馆时间到达后停止循环，保留最后一次成功预约，并提醒你自行签到。检测到官网已签到时也会停止。可随时点击“停止重约”；停止不会主动取消当前预约，已经发出的请求仍需等待结果。

例如选择 50 分钟间隔，在 08:00 成功预约、预计 14:00 到馆，正常情况下会在约 08:50、09:40、10:30、11:20、12:10、13:00、13:50 重约。每轮按实际提交时间重新计时，因此网络耗时可能使后续时刻略有偏移。14:00 不再取消，请及时签到。

**限制与失败处理：**

- 59 分钟签到期限及“重约刷新期限”来自使用者提供的信息，尚未通过真实取消与重约验证。学校规则和取消次数限制以官网为准；取消后座位可能被别人抢走，不能保证一直保留。
- 只支持当天计划和同一座位。不会自动换座，也不执行签到。重新预约失败会停止并明确提示当前未保留座位。
- 同时支持官网整段预约和自选起止时间。整段预约不受本地自选时段时长上限限制；取消前若无法校验原时段，保留预约并暂停。每轮重约使用新记录编号核实，不会把旧预约的取消状态误认为新预约状态。
- 取消结果不明时停止，点击“核实重约结果”只读取官网记录，不会再次取消。重约结果不明时保留待确认记录，可用已有的预约核实面板处理，再核实重约计划；恢复运行需重新开启。
- 后台每 5 秒检查计时。电脑必须保持开机、联网、不休眠，后台必须运行。Electron 关闭窗口会留在托盘，托盘“停止抢座与定时重约”或退出会停止计划。浏览器关闭后后台可以继续，但网页提醒依赖页面仍打开；Electron 支持后台系统通知。
- `renewal.json` 原子保存计划、阶段和最近操作记录，不保存登录令牌。正常等待阶段重启可恢复；取消或预约请求中途退出会要求核实，不自动重发。默认间隔下，醒来时距上次预约已达 58 分钟会暂停；选择 58、59 分钟时允许对应计时执行，超过所选间隔一分钟则暂停。每次取消前都核实官网是否仍允许取消；接近签到期限可能来不及重约，实际期限以官网为准。
- 普通抢座与重约互斥，避免两个任务同时提交；选择“下一次成功预约”时允许首次抢座。

取消接口来自学校前端的 [预约记录页面](https://libzw.csu.edu.cn/h5/assets/seat-record.1787201907183.js) 与其导入的接口模块：`POST /v4/space/cancel`，参数为官网预约记录的 `id`，并非座位 ID。成功判定只接受接口 `code === 0`。

本次验证使用隔离模拟接口和 Electron 界面测试，没有取消真实预约。可运行 `node --test tests/*.test.js` 验证定时、停止、重启、异常和界面交互。

## 超时核实与预约记录

提交预约只发送一次。请求超时、断网或响应无法解析时，程序暂停抢座并查询已有预约；只有有效状态、座位、日期和起止时段都匹配，才确认成功。暂未查到记录不能证明预约失败，因此不会直接重试或换座。

如果自动核实无法完成，页面提供“重新核实”和官网入口。请到官网核实对应座位和时段，再选择“官网已确认成功”或“官网已确认未成功”。确认未成功后，需要手动开始下一次任务。

待确认请求、最近 50 条已确认结果和通知状态保存在配置文件旁的 `bookings.json`，不包含登录令牌。请求发出前先保存待确认记录，重启后会恢复并尝试核实；页面“最近预约记录”可查看历史结果。文件损坏或无法写入时会显示错误并阻止新的预约提交。

自动核实从官网当前页面定位最新预约记录模块的接口声明，仅提取接口路径，不执行下载的脚本，避免官网升级后旧资源链接失效。连接不可用或无法匹配时会保留待确认状态。

## 取消预约与签离

地图用红色标记你的有效预约，图例显示“我的预约”；其他人的预约仍显示黄色。新增“我的座位”定位按钮，查看原预约日期不会改动你的抢座日期配置。取消或完全签离后自动移除红色标记。主界面保留操作与状态，详细说明可从右上角“使用帮助”展开。

在“查看预约结果”中，待签到的预约可以点击“取消预约”。检测到官网已签到后，入口自动改为“查看位置信息”，显示座位、区域及预约时间，并按官网允许的操作提供“临时签离”和“完全签离”。临时签离保留座位，须按官网时限返回并签到；完全签离结束本次使用并释放座位。

页面运行时每 30 秒同步一次官网状态，打开详情或点击“刷新状态”也会立即查询。每次操作前重新核实预约，使用官网记录编号提交；取消为普通请求，两种签离按官网协议加密。签离的定位要求由官网校验，失败原因会显示在详情中。

手动操作会停止当前定时重约计划。三个操作都只提交一次；超时或断网时保留待核实记录并阻止重复操作与重新抢座，重启后可通过“刷新状态”查询官网结果。测试只使用隔离的模拟接口，不会取消或签离真实预约。

## 托盘与时间检查

- Electron 桌面版关闭窗口后缩到托盘，继续运行。托盘显示正在抢座、已成功、已停止或结果待确认；双击恢复窗口，也可右键停止任务或退出。
- 网页版和轻量窗口保留原有退出方式。浏览器标签页关闭后，页面通知不可用。
- 实际预约在启动、每轮查询及最终提交前检查日期、开放时间、最长时长和时间粒度。查询期间更改区域或时段，会重新查询，避免使用旧配置提交。

## 常见问题

如果校区、楼层或地图加载失败，页面会显示原因，并提供“重新登录”“重新加载”和官网入口。登录过期时先重新登录，完成后自动加载地图；若提示无法连接学校，请先确认官网在当前网络下能够打开。失败后自动刷新会暂缓，避免重复请求排队。

登录一直等待时，在“登录管理”点击“打开登录窗口”，在学校统一身份认证页完成登录。后台静默检查不会禁用此按钮；需要人工认证时会结束静默等待并说明原因。已打开窗口时按钮变为“显示登录窗口”，也可点击“停止等待”后重试。浏览器连接、启动与登录等待均有超时，进度会显示已等待秒数。更新登录逻辑后需要从托盘退出并重启后台，单纯关闭 Electron 主窗口只会隐藏到托盘。

## 本地数据与配置

`config.json` 保存登录令牌和偏好；`bookings.json` 保存待核实请求、预约历史和通知状态；`browser-data/` 和 `.app-profile/` 保存浏览器会话。它们以及日志、签名密钥和构建产物均已加入 `.gitignore`，不会随源码上传。不要手动分享这些文件。

服务默认只监听本机回环地址。需要自定义端口或数据位置时，可以设置以下环境变量：

| 变量 | 用途 |
| --- | --- |
| `PORT` | 后端监听端口，默认 `8848` |
| `LIBSEAT_CONFIG_FILE` | 配置文件路径 |
| `LIBSEAT_BOOKINGS_FILE` | 预约记录文件路径 |
| `LIBSEAT_LOG_FILE` | 日志文件路径 |

## 已知限制

- 目前适配中南大学图书馆座位系统，不保证其他学校可直接使用。
- 学校接口、认证方式或静态资源版本变化可能导致功能失效。
- 自动登录依赖本机浏览器和有效学校会话，失效时需要重新登录。
- 本仓库不保证预约成功或后台长期持续运行，移动端使用限制见 Android README。
